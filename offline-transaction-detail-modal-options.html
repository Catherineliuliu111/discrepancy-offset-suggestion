Interaction idea

After confirm refund/payout fund, show the generated fund out transaction detail immediately and keep the user on the current flow until they acknowledge it.

  • Strong success state is easy to scan.
  • Identity fields are separated from accounting fields.
  • Biz Code is the only active control.
Trade-off: the modal covers the page context while it is open.

Right-side Detail Drawer

Keeps the Confirm Offline Result page visible while the generated transaction is reviewed in context.

Best for context

Interaction idea

Use a right-side drawer so users can still see the submitted refund or payout details behind the generated transaction.

  • Best continuity with the current page.
  • Easy to extend with audit information later.
  • Feels lighter than a blocking modal.
Trade-off: the narrower layout needs a longer vertical scan.

Interaction idea

  • Leaves room for future system metadata.
